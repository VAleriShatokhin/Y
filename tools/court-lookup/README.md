# Поиск даты судебного заседания по номеру дела (sudrf / ГАС «Правосудие»)

Скрипт `sudrf_case_lookup.py` открывает модуль «Судебное делопроизводство»
сайта районного/городского суда, решает капчу через **RuCaptcha / 2captcha**,
находит карточку дела и печатает **дату и время судебного заседания**.

## Установка

```bash
pip install -r requirements.txt
playwright install chromium
```

## Запуск

```bash
export RUCAPTCHA_KEY=ваш_ключ_rucaptcha
python sudrf_case_lookup.py \
    --court https://mitishy--mo.sudrf.ru \
    --case "13-298/2026"
```

Полезные флаги:

- `--show` — запустить браузер видимым (удобно для отладки селекторов).
- `--key`  — ключ RuCaptcha, если не задан через переменную окружения.

## Зачем это вообще нужно

Сайты судов (`*.sudrf.ru`) защищены:

1. **Антибот** — отдают `403` на «голые» HTTP-запросы (`curl`, `requests`,
   `WebFetch`). Поэтому используется реальный браузер через Playwright.
2. **Капча** на форме поиска — решается через сервис RuCaptcha.

## Ограничения в окружении Claude Code on the web

В облачном окружении действует сетевая политика по «белому списку».
Проверка показала: `github.com`/`pypi.org` доступны (`200`), а `sudrf.ru`
блокируется прокси (`403`). Поэтому **из стандартного окружения скрипт до суда
не достучится** — нужно расширить сетевую политику среды и добавить `*.sudrf.ru`
в разрешённые домены. Документация:
https://code.claude.com/docs/en/claude-code-on-the-web

## Запуск через GitHub Actions (без своей машины)

Раннеры GitHub имеют открытый интернет, поэтому это самый простой способ
получить дату, не настраивая ничего локально:

1. Добавьте секрет: **Settings → Secrets and variables → Actions →
   New repository secret**, имя `RUCAPTCHA_KEY`, значение — ваш ключ.
2. Откройте вкладку **Actions → «Court case lookup» → Run workflow**,
   введите номер дела (по умолчанию `13-298/2026`) и URL суда.
3. Дата заседания появится в логе шага **Run lookup**.

Workflow: `.github/workflows/court-lookup.yml`.

## Замечание про селекторы

Модуль `sud_delo` у разных судов отличается версиями вёрстки, поэтому имена
полей формы (номер дела, поле капчи, кнопка отправки) могут отличаться.
В скрипте перебирается несколько распространённых вариантов; если для
конкретного суда ничего не подошло — запустите с `--show` и поправьте
селекторы в `sudrf_case_lookup.py` под реальную страницу (в выводе печатается
фрагмент карточки для проверки).

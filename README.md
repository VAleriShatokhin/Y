Навигатор Развития 5+ 🌱

Автономный интерактивный дашборд для родителей детей 5 лет.

Это удобный инструмент сопровождения 30-дневного плана развития ребенка с фокусом на когнитивное развитие, исполнительные функции, речь, память, самоконтроль, игровые упражнения и базовые пищевые ориентиры.

Проект создан с идеей мягкого ежедневного развития через игру, регулярность, речь, простые правила и двигательную активность, а не через строгую "школьную дрессировку".

✨ Особенности

Полная автономность (Serverless): Приложение представляет собой один статический HTML-файл. Не требует бекенда, баз данных или серверов.

100% Приватность: Все данные пользователя (прогресс, заметки, имя ребенка, даты) сохраняются исключительно локально в памяти браузера (localStorage). Никакие данные не отправляются в интернет.

Готовый 30-дневный план: Контент уже встроен. Каждый день разбит на 4 категории: Речь, Логика, Самоконтроль и Питание.

Дневник наблюдений: Позволяет фиксировать настроение, уровень энергии ребенка и родительские заметки для каждого дня.

Визуальная статистика: Наглядный дашборд с отображением общего прогресса и прогресса по каждой из категорий.

Интеграция с Календарем: Экспорт как отдельных дней, так и всего 30-дневного плана целиком в формате .ics (поддерживается Apple Calendar, Google Calendar, Outlook и др.).

Адаптивный дизайн: Современный интерфейс, отлично работающий как на компьютерах, так и на смартфонах.

Импорт/Экспорт данных: Возможность сделать резервную копию своего прогресса (в формате .json) и перенести на другое устройство.

Версия для печати: Специальные стили для аккуратного вывода на принтер.

🚀 Как использовать (Установка)

Поскольку это single-file проект (все в одном файле), установка не может быть проще:

Скачайте файл index.html из этого репозитория.

Откройте его в любом современном браузере (Chrome, Safari, Firefox, Edge).

Готово! Можно начинать пользоваться.

Развертывание в интернете

Если вы хотите поделиться приложением с кем-то по ссылке:

GitHub Pages: Перейдите в настройки репозитория -> Pages -> выберите ветку main -> Save.

Netlify Drop / Vercel / Tiiny.host: Просто перетащите файл index.html в окно любого сервиса статического хостинга.

🛠 Технический стек

Проект написан с использованием современных веб-технологий, подключаемых через CDN:

React 18 (через CDN)

Tailwind CSS (через CDN)

Babel Standalone (для компиляции JSX прямо в браузере)

Lucide Icons (векторные иконки, встроенные в код)

Примечание: Использование CDN требует подключения к интернету при первом открытии файла для загрузки библиотек.

📖 Предметная логика

Основа проекта — 30-дневный план развития. Развитие ребенка идет не только через знания, но и через формирование когнитивной архитектуры: рабочей памяти, речевых функций, способности удерживать правило, переключаться между задачами.

Каждый день включает 4 короткие активности (по 10-20 минут в сумме):

Речь: пересказ, рифмы, описание.

Логика/память: сортировка, пазлы, поиск лишнего.

Самоконтроль/тело: игры с правилами (например, "замри"), дыхательные практики, баланс.

Пищевой ориентир: фокус на одном полезном продукте или привычке в день (вода, овощи, рыба и т.д.).
